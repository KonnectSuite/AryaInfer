Your own SearXNG instance, on this PC or a remote one. The instance must answer JSON: search.formats in its settings.yml needs json next to html.

Credits and host findings

The interface, wordmark, fonts and colors come from the AryaAI brand kit. AryaInfer is a fork of PolyStrata, which is a fork of Niko1221’s original Strata. Thanks to both projects and their contributors. AryaInfer on GitHub. Chats, settings and the API key are kept in this browser only.

Configured for our i9-14900KF, RTX 4070 Ti SUPER 16 GB, 64 GB RAM, Windows 11 host. We benchmark against this setup and update the docs with our findings as measurements become available.

Qwen3.8 Flash Next: the earlier text-only measurements were 86.1 tokens/s for short chat and 95.6 tokens/s in agent-style speed sessions (medians). All three recall trials at 258,300 input tokens, 18 small coding-agent sessions and 3 development DSH adapter checks passed. Vision was enabled and checked separately afterward; those speed measurements do not include vision.

Qwen3.6 Q4 and Q8: 262,144-token context with GPU vision enabled. Each quant passed 36 bounded coding sessions, 12 image checks, 6 recall trials and 3 combined long-context coding/image sessions. Each also passed 3 development DSH adapter checks. Q4 offers more memory headroom on this host; Q8 briefly left about 0.1 GiB of system RAM available. These fixtures do not establish general coding accuracy or full desktop-workflow qualification. Host benchmark details.

MiniCPM-V 4.7 Q4: 262,144-token context with GPU vision. Low reasoning passed 18/18 bounded coding sessions; both reasoning modes passed all 3 long coding/image sessions. All 12 image checks, 6 recall trials and 3 development DSH adapter checks passed. Coding scores use the corrected validator; original records remain archived. MiniCPM host results.

Ornith APEX-I-QUALITY: 262,144-token context with GPU vision. Low reasoning passed 18/18 bounded coding sessions and 3/3 long coding/image sessions, including all image IDs. All 12 image checks, 6 recall trials and 3 development DSH adapter checks passed. All model host results.

Gemma 4 26B-A4B UD-Q4_K_M: 262,144-token capacity, GPU vision. Bounded coding off 16/18, low 13/18; recall 6/6, long coding 2/3, development adapter 3/3. Low reasoning at 4K output passed 18/18 short and 2/3 long coding/image sessions. See the separate budget comparison. Measured results and limits.

Tiel Coder 35B-A3B UD-Q4_K_XL: 262,144-token capacity, GPU vision. Bounded coding off 16/18, low 18/18; recall 6/6, long coding 3/3, development adapter 3/3. Image checks 8/12; build-ID transcription misses are retained. Measured results and limits.

LFM2.5-24B-A2B UD-Q4_K_XL: 131,072-token capacity, text only. Native-thinking coding at 4K output 18/18; recall 2/6, long coding 0/3, development adapter 3/3. Initial forced-off failures are archived. Measured results and limits.
